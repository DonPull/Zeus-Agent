## 2. Benchmark Execution Loop
You will sequentially process all 10 prompts from:
`D:\Hristian projects\Zeus-Agent\scripts\eval_harness\prompts\10_agentic_prompts.json`

For each prompt in order (Prompt 1 through Prompt 10):

### Step 1: Execute the Test in Repo B
Run the pre-built benchmark test runner in Repo B:
```zeus-directive
{"type":"run_command","command":"npx playwright test tests/advanced_e2e/benchmark_runner.spec.js --grep \"Prompt <N>\"","cwd":"E:\\Programs\\Zeus-Agent"}
```
*(Where `<N>` is the prompt number, e.g. `Prompt 1`, `Prompt 2`, etc.)*

### Step 2: Inspect Execution Logs & Artifacts
1. Read the test results and backend debug log:
   - Check `E:\Programs\Zeus-Agent\tests\advanced_e2e\results\` for the generated test artifacts and `debug_log.txt`.
2. Inspect whether all expected deliverables (images, CSVs, databases, reports) were created and validated.

### Step 3: Apply Deduction-Based Scoring (Base = 10.0)
- **Hard Failure (-10.0 pts, Score = 0)**: Goal was not achieved, required artifacts are missing, or python verification assertions failed.
- **Engine / Stability Errors (-3.0 pts each)**: Any `MALFORMED directive`, JSON parsing retry, unhandled crash, or HTTP 500 in logs.
- **Security / Gatekeeper Refusals (-2.5 pts each)**: Infinite loops on security boundaries or unhandled `GATEKEEPER_DENIED`.
- **Tool Discipline & Context Clutter (-1.5 pts each)**: Redundant file reads, duplicate tool executions, intermediate conversational narration without a directive block, or overwriting unrelated files.
- **Language Adherence (-2.0 pts)**: Any non-English conversational narration or action planning text.
- *RULE: You MUST cite specific line numbers and quoted text from `debug_log.txt` for each deduction.*

### Step 4: Self-Refinement or Progression
- **If Score < 8.5 / 10 (Prompt Failed)**:
  1. Diagnose the exact failure point from the logs.
  2. Modify the code in **Repo B only** (`E:\Programs\Zeus-Agent\src-tauri\src\`, `E:\Programs\Zeus-Agent\src-tauri\src\prompts\`, or `E:\Programs\Zeus-Agent\src\`).
  3. Run `cargo check --lib` and `npm run build` with `cwd: "E:\\Programs\\Zeus-Agent"` to verify clean compilation. Fix any compile errors immediately.
  4. Update `D:\Hristian projects\Zeus-Agent\EVAL_STATUS.md` with the trial notes and score.
  5. **Re-run Step 1 for the current prompt immediately** until it scores $\ge 8.5/10$.
- **If Score >= 8.5 / 10 (Prompt Passed)**:
  1. Commit the improvement in Repo B:
     `git commit -m "refactor(agent): improve Prompt <N> benchmark pass (Score: X/10)"` (with `cwd: "E:\\Programs\\Zeus-Agent"`).
  2. Update `D:\Hristian projects\Zeus-Agent\EVAL_STATUS.md` recording that Prompt N has PASSED.
  3. Advance to Prompt $N + 1$.
